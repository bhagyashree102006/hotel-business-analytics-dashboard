# 🏨 Hotel Business Analytics Dashboard

## 📌 Project Overview

The Hotel Business Analytics Dashboard is an internship project developed to analyze hotel booking data and generate meaningful business insights.

The project focuses on understanding booking patterns, cancellation behaviour, pricing, customer segments and hotel performance.

---

## 🎯 Objectives

- Analyze hotel booking patterns
- Understand cancellation behaviour
- Compare hotel performance
- Analyze customer segments
- Study Average Daily Rate (ADR)
- Analyze length of stay
- Identify high-demand periods
- Generate business recommendations

---

## 🛠️ Technology Stack

- Python
- Pandas
- Matplotlib
- Plotly
- Streamlit

---

## 📊 Project Components

### 1. Interactive Streamlit Dashboard

The dashboard provides:

- KPI cards
- Hotel filters
- Booking status filters
- Year and month filters
- Market segment filters
- Customer type filters
- Interactive charts
- Business performance analysis

### 2. Exploratory Data Analysis

EDA includes:

- Dataset overview
- Missing value analysis
- Duplicate analysis
- Descriptive statistics
- ADR distribution
- Lead-time analysis
- Length-of-stay analysis
- Correlation analysis

### 3. Business Insights

The project identifies:

- Top-performing hotel
- Highest-demand month
- Highest ADR hotel
- Cancellation behaviour
- Customer segment patterns
- Business recommendations
